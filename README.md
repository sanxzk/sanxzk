## 🚀 Featured Project

### ☁️ CloudVault

A serverless cloud media gallery built with **React, TypeScript, and AWS**.

* 📁 Upload and view images and videos using **Amazon S3**
* 🔐 Secure uploads using **short-lived S3 presigned URLs**
* ⚡ **API Gateway + Lambda** for generating upload URLs
* 🌐 **CloudFront + Origin Access Control (OAC)** for secure media delivery
* 🔒 Private S3 bucket architecture
* 🔑 AWS IAM roles with scoped permissions
* 🌍 Custom domain with **AWS ACM**
* 🔄 CI/CD using **GitHub Actions**
* 🗄️ Supabase for **Postgres, Authentication, and Row Level Security**
